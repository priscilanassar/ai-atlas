# Atlas wordmark animation fonts

Allura, Great Vibes, Inter, Manrope and Space Grotesk are served locally as
Google Fonts subsets containing only `ATLAS`. Font data comes directly from
`fonts.googleapis.com` / `fonts.gstatic.com`; the corresponding OFL notices
come from the official `google/fonts` repository and are included here.

Helvetica Neue / Helvetica are used when installed on the visitor's device.
Inter is the bundled fallback. No proprietary Helvetica file is distributed.
Georgia is the system serif variant. No font comes from DaFont.

To refresh the subsets, run `curation/download_atlas_fonts.py` with network access.
